# ボドゲタイマー v0.7.5

2〜6人対応の持ち時間タイマーです。SOLO / ONLINE ROOMに対応します。

## v0.7.5 修正
- 規定時間プリセットの秒→ミリ秒変換バグを修正
- SOLOで選択中の規定時間ボタンが白表示されるよう修正
- SOLOの `+0:00 / -0:00` 問題を修正
- ONLINE ROOMに旧バージョンの誤った `30 / 60 / 90 / 120ms` が残っていても `30 / 60 / 90 / 120秒` として自動修復

GitHub Pagesでは `index.html` のみ差し替えれば更新できます。`firebase-config.js` は既存のものをそのまま使用してください。
