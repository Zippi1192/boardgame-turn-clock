# ボドゲタイマー v0.7.4

ONLINE ROOM の規定時間が 0 秒になるケースを修正した版です。

## 修正点
- ONLINE ROOM の `baseMs` が未設定・0・不正値の場合、60秒へ自動補正
- 規定時間の表示・±ボタン・次ターン加算で必ず有効な規定時間を利用
- 人数を増やした際、新規プレイヤーが 0:00 で追加される問題を修正
- `turns=0` かつ `remain=0` の未開始プレイヤーを規定時間へ自動補正
- 既存の壊れたROOMも、入室時に可能な範囲で自動修復

GitHub Pages では `index.html` のみ差し替えてください。既存の `firebase-config.js` はそのまま使用します。
