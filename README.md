# ボドゲタイマー v0.7.3

2〜6人対応のボードゲーム用持ち時間タイマーです。SOLO / ONLINE ROOMに対応。

## v0.7.3 更新
- ONLINE ROOM内の設定変更を全端末へリアルタイム反映
- 規定時間変更時も現在の残り時間を保持し、次ターン以降の加算量だけ変更
- 現在選択中の規定時間ボタンを白表示
- 「部屋を作成して入室」「ROOMに入室」と導線を明確化
- 入室後はタイマー画面を自動表示し「ROOMに入室しました」と通知

## 公開
GitHub Pagesの既存 `index.html` をこの版へ差し替えてください。`firebase-config.js` は現在のものをそのまま使用できます。
